# Saarthi — Project Abstract

Saarthi is an AI-inspired voice-guided browser assistant intended to support people with limited digital literacy. Many users find online forms, portals, and service websites difficult because interfaces contain unfamiliar labels, menus, and multi-step workflows. Saarthi aims to make these interfaces easier to understand by combining webpage context with spoken, plain-language guidance.

The browser extension inspects visible interactive elements such as buttons, links, and form fields. Users can request an explanation or speak simple commands. The prototype can describe page controls, highlight a likely relevant element, and present a confirmation before activating a button. A mock university portal is provided as a safe demonstration environment.

The prototype uses Chrome Extension Manifest V3, JavaScript DOM APIs, and browser speech capabilities. Its current command interpretation is rule-based; a language-model-based intent engine and multilingual support are planned extensions. Saarthi's central goal is to improve digital accessibility and user confidence while preserving user control over important actions.

**Keywords:** Digital accessibility, voice interface, browser extension, assistive technology, human-computer interaction.
